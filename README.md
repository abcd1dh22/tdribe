# TeleCloud

টেলিগ্রাম চ্যানেলকে স্টোরেজ বানিয়ে ব্যক্তিগত ক্লাউড এপ (Flutter)।

## সেটআপ
1. টেলিগ্রামে @BotFather থেকে বট বানিয়ে টোকেন নিন।
2. একটি প্রাইভেট চ্যানেল খুলে বটকে অ্যাডমিন করুন (Post, Delete, Pin messages অনুমতি সহ)।
3. চ্যানেল আইডি (-100...) জেনে নিন।
4. এপের সেটিংসে টোকেন ও চ্যানেল আইডি দিন।

## APK বানানো
1. এই ফোল্ডারের সব ফাইল (লুকানো `.github` সহ) একটি GitHub রিপোতে পুশ করুন।
2. Actions ট্যাবে `Build APK` চলবে (বা Run workflow চাপুন)।
3. শেষ হলে রানের Artifacts থেকে `telecloud-apk` নামান।

## নোট
- ১৯MB-এর বড় ফাইল নিজে নিজে ভাগ হয়ে আপলোড হয় ও ডাউনলোডে জোড়া লাগে।
- ব্যাকআপ চ্যানেলে পিন হয়; নতুন ফোনে রিস্টোর চাপলেই তালিকা ফিরে আসে।

## ড্রাইভের মতো সুবিধা
- এপের ভেতরেই ছবি (জুম ও সোয়াইপ), ভিডিও, PDF ও টেক্সট ফাইল দেখা যায়।
- ফোল্ডার, সার্চ, সাজানো (নাম/তারিখ/আকার), গ্রিড ও লিস্ট ভিউ।
- লং-প্রেসে একাধিক ফাইল বাছা, তারকা, সরানো, নাম বদল।
- ট্র্যাশ: মুছলে আগে ট্র্যাশে যায়; সেখান থেকে ফেরানো বা স্থায়ীভাবে মোছা (চ্যানেল থেকেও) যায়।
